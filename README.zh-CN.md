# 散落文件归属诊断器

指一个乱糟糟的目录，它告诉你每一个散落的 `.exe` / `.dll` 到底属于哪个已安装的软件——**在你动手删除之前**。

仅支持 Windows。单个 PowerShell 脚本，零依赖，不需要安装任何东西。严格只读：不改、不移动、不删除任何文件。

---

## 它解决什么问题

盘符根目录或下载目录会慢慢堆满没人认得出来的文件：

```text
D:\
|-- iTunes.exe            这是哪个程序？
|-- WebKit.dll
|-- vcruntime140_1.dll    这个能删吗？
|-- gnsdk_musicid.dll
|-- setup.tmp
`-- pagefile.sys          删了系统会出问题
```

靠猜的代价很高：删错文件会直接搞坏一个已安装的软件，删到 Windows 系统文件会让系统不稳定。这个工具用证据回答"这文件是谁放的"，而不是猜。

## 快速开始

```powershell
# 看一个盘符根目录
.\FileOriginScan.ps1 -Path D:\

# 连子目录一起看，跳过签名校验以加快速度
.\FileOriginScan.ps1 -Path "$env:USERPROFILE\Downloads" -Recurse -SkipSignature
```

更喜欢点鼠标？双击 `Run-FileOriginScan.cmd`，输入目录（也可以把文件夹直接拖到这个 .cmd 上），再回答是否包含子目录。

每次运行都会在脚本同级的 `reports\` 里生成三份报告：给人看的 HTML、给脚本用的 JSON、给 Excel 用的 CSV。

## 判定原理

每个文件会同时比对几路互相独立的证据，命中最强的那个作为结论：

| 证据 | 含义 | 置信度 |
| --- | --- | --- |
| **安装路径** | 文件所在目录正好是某个已安装软件在卸载注册表里登记的 `InstallLocation` | 高 |
| **产品信息** | 文件的版本资源（ProductName / FileDescription / OriginalFilename）指向某个已安装软件 | 中 |
| **厂商同源** | 文件的 CompanyName 或数字签名者与该软件的 Publisher 一致 | 低 |
| **内置组件表** | 文件名命中常见公共库（VC++ 运行库、Bonjour、WebKit、ICU、SQLite、DirectX 等） | 参考 |

在归属判定之外还有四层检查：

- **PE 头解析**：读取真实架构（`x86` / `x64` / `ARM64`），32/64 位混放一眼可见。
- **数字签名状态**：统计并列出没有有效签名的文件。未签名不等于有问题，但它是排查线索。
- **来源不明判定**：既无版本信息、又无数字签名、也匹配不到任何已安装软件的可执行文件，会被单独标出——这正是"卸载残留还是便携程序"的典型情形。
- **系统文件保护**：`pagefile.sys`、`hiberfil.sys`、`swapfile.sys` 等会被识别为系统保留文件并明确标注禁止删除，同时给出官方支持的调整方式。

已安装软件信息读自 `HKLM`（含 `WOW6432Node`）与 `HKCU` 的卸载注册表项。如果某个软件在注册表里登记的安装目录就是盘符根目录，报告会直接点明——那是"根目录全是程序文件"最常见的原因。

## 输出

| 文件 | 用途 |
| --- | --- |
| `*.html` | 阅读用报告：概览、结论、归属明细、完整文件清单、来源不明清单、建议动作 |
| `*.json` | 同数据供脚本调用（属性名为英文，结构稳定） |
| `*.csv` | 文件清单，便于 Excel 处理 |

小目录的控制台输出示例：

```text
  文件总数    : 5
  占用空间    : 2.1 MB
  已归属      : 2
  未归属      : 1
  来源不明    : 1
  未签名      : 1
  来源数量    : 1
  架构分布    : x64 2
```

完整报告样式见 [examples/sample-report.html](examples/sample-report.html)（用浏览器打开）。

## 参数

| 参数 | 作用 |
| --- | --- |
| `-Path <目录>` | 要扫描的目录，省略时交互式询问 |
| `-Recurse` | 包含子目录 |
| `-MaxFiles <数量>` | 限制分析的文件数（默认 5000），发生截断会明确说明 |
| `-SkipSignature` | 不做数字签名校验（更快，精度略降） |
| `-ForceSignature` | 文件超过 500 个时仍强制校验签名（较慢） |
| `-OutDir <目录>` | 报告输出目录（默认脚本同级 `reports\`） |
| `-OutFile <文件>` | 指定 HTML 报告路径，JSON/CSV 与其同目录同名 |
| `-Quiet` | 只在控制台打印报告路径 |

## 运行环境

- Windows 10 / 11（或 Windows Server 2016+）
- Windows PowerShell 5.1（系统自带）或 PowerShell 7+
- 不需要管理员权限：只读文件元数据、PE 头、数字签名和当前用户的注册表

## 安全边界

工具在设计上就是只读的：没有删除、移动或清理模式。它只解释"为什么认为这个文件属于某个软件"，是否处理始终由人决定。

## 已知限制

- 只能识别登记在卸载注册表里的软件；绿色便携程序、已卸载软件的遗迹会归入"来源不明"。
- 文件超过 500 个时默认跳过签名校验（可用 `-ForceSignature` 覆盖）。
- 厂商匹配基于分词，对拉丁字母公司名效果最好；中文产品名走产品信息匹配。
- 判定是带置信度的推断而不是证明，所以报告会写清每个文件的判定依据供你复核。

## 测试

```powershell
./tests/Test-FileOriginScan.ps1
```

测试是黑盒的：它会搭建一个临时目录树和一条临时卸载注册表项，像用户那样调用工具，再对生成的 JSON / HTML / CSV 做断言（23 项检查，覆盖归属判定、组件表、系统文件、来源不明、递归、`-MaxFiles`、`-SkipSignature`、空目录以及真实 PE 架构）。Windows PowerShell 5.1 与 PowerShell 7 下都能跑，见 `.github/workflows/ci.yml`。
